# NOVA 발표자료 v16 (2026-09-28 멘토링 반영)

`NOVA_발표_v14`를 5회차 멘토링 피드백에 맞춰 재구성한 발표자료입니다.

## 파일

| 파일 | 설명 |
|---|---|
| `NOVA_발표_v16.pptx` | 수정본 (4:3, 원본 Google 템플릿 유지, 33장, 장표별 발표자 노트 포함) |
| `NOVA_전체아키텍처.drawio` | 전체 아키텍처 원본 (Google Cloud 공식 아이콘, diagrams.net에서 편집) |
| `NOVA_전체아키텍처.png` | 위 다이어그램 렌더링 이미지 (슬라이드 8에 사용) |

## 주요 변경

- 발표 흐름: `배경과 설계 → 서비스 구축 → 보안과 운영 → 검증과 시연 → 계획과 회고`
- 목차 · 간지 · 상단 탭의 섹션 이름을 하나로 통일, 간지는 목차에서 현재 섹션을 강조하는 형태
- 신규 장표: 배경(온프레미스의 한계), 요구사항, 설계 결정(대안 비교), 요구사항 충족, 부록(구성 스펙 · 예상 질문 · 트러블슈팅)
- 구축 설명 순서: 네트워크 → 로드밸런싱 → WEB/WAS(공통 MIG 설계 + 비교표) → DB → 보안 → 모니터링
- 시연 자리 4장을 검증 결과 표 + 시연 1장으로 통합
- 본문 장표마다 굵은 한 줄 메시지 제목과 설정값 · 선택 이유 추가
- 글꼴: 영문 Calibri + 한글 Noto Sans KR (Google Slides 기본 제공)

## Google Slides에서 쓰는 방법

1. `NOVA_발표_v16.pptx`를 Google Drive에 올리고 **Google Slides로 열기**
2. 팀 덱에 일부만 가져오려면 팀 덱에서 `파일 > 슬라이드 가져오기`로 필요한 장표 선택
3. 다이어그램을 고치려면 `NOVA_전체아키텍처.drawio`를 diagrams.net에서 열어 수정 후 PNG로 내보내 교체

## 남은 작업

- 슬라이드의 빨간 `[ ]` 항목(WEB 머신 타입 · 템플릿명, Cloud SQL 사양, 월 비용, 개인 회고)을 채우기
- 시연 영상 3편 삽입(슬라이드 23), 각 구축 장표에 콘솔 캡처 추가
- 검증 수치(재생성 시간, WAF 탐지 건수 등)를 담당자가 최종 확인
